FAQ

Straight answers.

Where do my keys live?

Nowhere in Parzi. Each agent is installed with its vendor's official installer and signed in with its own login. Parzi never stores keys or tokens. Passwords come from Bitwarden's own prompt, so Parzi never sees the master password.

Which agents ask before every change?

Claude Code, Codex and OpenCode. Grok, Antigravity and Cursor can change files without asking — Settings and parzi providers say so, and the thread says so once.

Can an agent write outside my project?

It may read anywhere, but a write outside the session's folder is never approved on your behalf: you are asked, and a run with nobody to ask is refused.

What is the Brain?

Plain markdown in ~/.parzi/brain. Pinned notes go in full; the rest are one-line summaries the agent reads with brain_read when the task needs it. Full text is capped at about 12k characters.

How much does it cost?

MIT-licensed. Bring your own agent subscriptions — parzi providers spends no quota checking them.
